# Survey Code & Live Preview

KDAnalytiks provides developer-friendly **Survey Code** tools alongside real-time **Live Preview** testing modes to inspect and validate your survey before deployment.

---

## Survey Code Mode

The **Survey Code** feature allows advanced users to build with or edit the underlying JSON / XML schema representation of a survey.

### Key Capabilities of Survey Code

- **Schema Inspection**: View the complete structural definition of questions, logic rules and validation schemas in standardized JSON.
- **Batch Editing**: Quickly update question option lists or variable keys in code view.
- **Code Export & Import**: Copy the survey code JSON to migrate questionnaires between workspaces or backup survey definitions offline.

### Accessing Survey Code

In the Survey Builder, click the **Code View (`</>`)** tab in the top utility bar to toggle between the visual canvas and raw code mode.
For mobile users **Code View** can be found under More

---

## Live Preview Mode

Before publishing or sharing a survey with respondents, use **Live Preview** to test the respondent experience:

### Features of Live Preview

- **Multi-Device Simulation**: Toggle between **Desktop**, **Tablet** and **Mobile** viewports to ensure responsive rendering across all screen sizes.
- **Interactive Logic Testing**: Test skip logic, display conditions and required question validation without creating actual response database entries.
- **Language Switcher Test**: Test how localized translations render for non-English respondents.

### How to Launch Live Preview

Click the **Preview** button in the Survey Builder header at any time. Preview submissions are sandboxed and will not affect live response datasets.
