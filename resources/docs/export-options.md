# Data Export Packages (Excel, Word, SPSS)

KDAnalytiks offers robust data export packages suitable for academic statistical analysis, corporate presentations and raw data archiving.

---

## Supported Export Formats

Navigate to **Reports** -> **Export Data** to generate files in any of the following formats:

### 1. Microsoft Excel (.xlsx)

- Formatted data sheets with question headers and response rows.
- Separate tab sheets for summary metrics and coded numerical values.

### 2. Statistical Packages (SPSS & R)

- **SPSS (.sav)**: Export data pre-coded with variable names, value labels and missing value indicators ready for SPSS analysis.

### 3. Microsoft Word (.docx) & PDF Executive Summaries

- Complete written executive reports with embedded high-resolution charts, tables and narrative summaries.

### 4. Raw CSV & JSON Data

- Download unformatted raw data files for custom database imports or custom script processing.
